# ⛸️ Snabbstart - Skating Weather App

## 🚀 Starta Appen (3 Steg)

### 1. Navigera till Projektet
```powershell
cd C:\Users\jespe\skating-weather-app
```

### 2. Starta Appen för Web
```powershell
npm run web
```

Appen öppnas automatiskt på `http://localhost:19006`

## 🎯 Testa Appen

1. Klicka på "📍 Välj plats"
2. Välj t.ex. "🇫🇮 Kilpisjärvi" eller "🇸🇪 Abisko"
3. Se väderdata, graf och isanalys!

## 📱 Andra Plattformar

### Expo Go (Mobil)
```powershell
npm start
```
Scanna QR-koden med Expo Go-appen

### Android
```powershell
npm run android
```

### iOS (Mac endast)
```powershell
npm run ios
```

## 🌐 Bygg för Production

```powershell
npm run web:build
```

Skapar `web-build/` mappen med statiska filer.

## 🔧 Felsökning

### Problem: Port redan använd
```powershell
npx expo start --port 19001
```

### Problem: Cache-fel
```powershell
npx expo start --clear
```

### Problem: npm install fel
```powershell
npm cache clean --force
npm install
```
